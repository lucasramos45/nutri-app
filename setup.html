Por que a chave é necessária?
A senha serve para embaralhar a chave de acesso, que é o que realmente abre as suas informações. Trocar a senha significa embaralhar essa chave outra vez, e para isso ela precisa estar em mãos.

Isso é seguro?
Sim. O embaralhamento acontece dentro do seu navegador e nada é enviado para a internet. A chave nunca fica legível: quem não souber a senha vê apenas um texto sem sentido. Por isso, a força da proteção é a força da senha — uma senha curta ou óbvia é o único ponto fraco possível.

E se eu esquecer a senha?
Não existe recuperação automática. O caminho é voltar aqui com a chave de acesso e definir uma senha nova.

Detalhe técnico
A chave é cifrada com AES-GCM de 256 bits. A chave de cifra é derivada da senha por PBKDF2-SHA256 com 600.000 iterações e sal aleatório de 16 bytes. A cifragem usa a WebCrypto API nativa do navegador; o resultado é gravado no arquivo auth.json do repositório do site, via API do GitHub, usando a própria chave de acesso informada acima.

Senha trocada

Pronto, não precisa fazer mais nada. A senha nova já vale — use ela no próximo acesso.

Importante
Guarde a senha em um lugar seguro. Ninguém consegue recuperá-la: se ela for esquecida, o único caminho é voltar aqui com a chave de acesso e definir outra.
