Configurar acesso

Esta página gera o arquivo auth.json, que guarda o token do GitHub cifrado com a sua senha (AES-GCM 256 + PBKDF2). Tudo acontece aqui no seu navegador — nada é enviado para lugar algum.

A força da proteção é a força da senha. Quem baixar o auth.json pode tentar adivinhá-la offline. Use 12 caracteres ou mais, sem palavras óbvias nem datas.

Pronto

Agora coloque este arquivo na raiz do repositório público (nutri-app), com o nome exato auth.json.

Este conteúdo é seguro de compartilhar em comparação ao token puro — ele está cifrado. Mesmo assim, não o publique fora do necessário.

  1. Abra github.com/lucasramos45/nutri-app
  2. Add file → Upload files (ou Create new file e cole o conteúdo)
  3. Nome do arquivo: auth.json
  4. Commit changes

Depois disso, o login no site passa a ser o usuário e a senha que você definiu aqui.
